# 团队工作区纵向布局设计

## 目标

将团队管理页中的“团队设置”和“消息流画布”从左右双栏改为上下单列排列，让两块内容都使用完整页面宽度。

## 布局

- “团队设置”位于上方，保持内容自然高度。
- “消息流画布”位于下方，占满可用宽度。
- 两块面板沿用现有间距、边框、背景和圆角，不改变页面其他区域。
- 画布内部继续保留现有横向编辑区域和溢出滚动能力，不改变节点、连线及键盘交互。

## 范围

- 仅修改团队管理页工作区布局样式。
- 不修改团队数据、保存逻辑、组件顺序或消息流行为。
- 不修改 Run 详情页。
- 移动端继续保持单列布局。

## 验证

- 增加样式回归检查，确保工作区使用单列网格。
- 运行桌面前端完整测试和生产构建。
- 检查代码差异，确认没有超出团队管理页布局范围。
