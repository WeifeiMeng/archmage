# Archmage

Archmage is a local-first collaboration runtime that connects local agent providers and lets capability-oriented agents work together on one code workspace.

The first executable slice connects a real Codex CLI provider and runs four logical agents—Designer, Coder, Tester, and Reviewer—through explicit, auditable handoffs in an isolated Git worktree.
